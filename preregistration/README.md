# Ön Tescil Dosyaları

PROTOCOL.md §4.5 kuralı: her faz başlamadan önce `faz_N.md` dosyası yazılır
(hipotez, metrik, eşik, durma kararı) ve deney koşulduktan sonra
değiştirilmez. Revizyon gerekirse yeni dosya (`faz_N_v2.md`) açılır ve
nedeni belirtilir.

Henüz hiçbir faz ön tescil edilmedi — Faz 0 (altyapı) ön tescil gerektirmez,
çünkü hiçbir hipotez testi içermiyor. Faz 1 başlamadan önce
`faz_1.md` buraya yazılacak.
